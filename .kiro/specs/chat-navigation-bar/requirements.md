# 需求文档

## 简介

本文档定义了聊天导航栏组件系统的需求，该系统用于显示群聊和私聊的头部信息。导航栏由两部分组成：顶部区域显示链和钱包信息，底部区域显示聊天详细信息。不同等级的聊天通过独特的背景颜色进行区分。

## 术语表

- **导航栏组件**：显示在聊天界面顶部的头部 UI 组件
- **顶部区域**：包含区块链网络、钱包连接和地区信息的上半部分
- **底部区域**：包含聊天特定信息（群组名称、等级、地址、成员数量）的下半部分
- **等级徽章**：显示聊天群组等级的视觉指示器（LV1-LV6）
- **背景主题**：根据聊天等级应用到导航栏的配色方案
- **群聊模式**：用于官方群聊的导航栏变体
- **私聊模式**：用于一对一对话的导航栏变体
- **钱包地址**：以截断格式显示的区块链地址（0x...）

## 需求

### 需求 1

**用户故事：** 作为查看群聊的用户，我希望看到包含链信息和群组详情的导航栏，以便快速识别我所在的聊天及其等级。

#### 验收标准

1. 导航栏组件应当显示包含"BNB Chain"文本、"Connect wallet"按钮和带国旗图标的地区指示器的顶部区域
2. 导航栏组件应当显示包含群组图标、群组名称、等级徽章和钱包地址的底部区域
3. 当聊天等级为 LV1 时，导航栏组件应当应用浅蓝色背景主题
4. 当聊天等级为 LV2 时，导航栏组件应当应用蓝色背景主题
5. 当聊天等级为 LV3 时，导航栏组件应当应用紫色背景主题
6. 当聊天等级为 LV4 时，导航栏组件应当应用黄色背景主题
7. 当聊天等级为 LV5 时，导航栏组件应当应用红色背景主题
8. 当聊天等级为 LV6 时，导航栏组件应当应用黑色背景主题

### 需求 2

**用户故事：** 作为查看私聊的用户，我希望看到包含对方信息的导航栏，以便识别我正在与谁聊天。

#### 验收标准

1. 导航栏组件应当支持私聊模式，显示用户特定信息而非群组信息
2. 当处于私聊模式时，导航栏组件应当显示联系人姓名和钱包地址
3. 导航栏组件应当在左侧显示带成员数量指示器的返回按钮
4. 导航栏组件应当在右侧显示三点菜单按钮

### 需求 3

**用户故事：** 作为用户，我希望导航栏能够响应式适配不同屏幕尺寸，以便在各种设备上使用应用。

#### 验收标准

1. 导航栏组件应当在移动端屏幕尺寸上保持适当的间距和对齐
2. 导航栏组件应当使用省略号截断过长的钱包地址以适应可用空间
3. 导航栏组件应当确保所有可交互元素（按钮、链接）具有至少 44x44 像素的足够触摸目标

### 需求 4

**用户故事：** 作为开发者，我希望导航栏组件可复用且可配置，以便在不同聊天界面轻松实现。

#### 验收标准

1. 导航栏组件应当接受聊天类型（群聊或私聊）的属性参数
2. 导航栏组件应当接受聊天等级（LV1-LV6）的属性参数
3. 导航栏组件应当接受聊天名称、图标、地址和成员数量的属性参数
4. 导航栏组件应当接受链名称和地区的属性参数
5. 导航栏组件应当为可交互元素（返回按钮、菜单按钮、钱包连接）提供回调函数

### 需求 5

**用户故事：** 作为用户，我希望能够与导航栏元素交互，以便执行返回、连接钱包或访问聊天选项等操作。

#### 验收标准

1. 当用户点击返回按钮时，导航栏组件应当触发导航回调以返回上一屏幕
2. 当用户点击"Connect wallet"按钮时，导航栏组件应当触发钱包连接回调
3. 当用户点击三点菜单按钮时，导航栏组件应当触发菜单回调以显示聊天选项
4. 当用户点击钱包地址时，导航栏组件应当触发复制到剪贴板的操作
